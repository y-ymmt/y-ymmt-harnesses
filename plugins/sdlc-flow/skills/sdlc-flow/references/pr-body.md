# PR 説明の形

プロジェクトに PR テンプレートが無いときに使う。中身は状態ファイルから組み立てる。空になる節は消す。

```markdown
## 概要
<チケット番号> <何ができるようになるかを 1〜2 文で>

## なぜ（Intent）
- Problem: ...
- Proposed outcome: ...
- 出典: <仕様書・チケットの URL>

## 何を変えたか
<html-plan の確定した第 1 層の主張、または plan mode の計画の要点を箇条書きで>

## 決定事項
| 問い | 決めたこと |
|---|---|
| ... | ...（既定のまま / 変更） |

## テスト
- 追加・変更したテスト: ...
- 実行したチェック:
  - `make test`: pass
  - `make lint`: pass

## レビュー
- ローカルレビュー（code-review ほか）で直した点: ...

## 未解決事項
- [ ] <他の人に聞くこと（相手）>
- [ ] <環境の理由で回せなかったチェック（理由）>
- [ ] <直さなかったレビュー指摘（理由）>
```
